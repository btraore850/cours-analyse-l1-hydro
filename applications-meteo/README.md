# Applications en météorologie

Ce dossier accueillera les jeux de données, feuilles de calcul et scripts illustrant l'Analyse appliquée aux sciences atmosphériques.

Exemples possibles : évolution de température, gradients, variations temporelles, bilans simplifiés et équations différentielles.
