# Travaux pratiques — Analyse L1 Hydrologie

Le module prévoit 5 h de TP. Voici un **plan proposé**, non encore définitivement programmé :

1. Tableur : intensité et cumul des précipitations.
2. Tableur ou R : débit, hydrogramme, volume écoulé.
3. R ou Python : convergence des séries et sommes partielles.
4. R ou Python : cycles périodiques et séries de Fourier.
5. Tableur, R ou Python : bilan hydrique et modèle de stockage.

Les fichiers numériques et supports de TP seront ajoutés progressivement.
