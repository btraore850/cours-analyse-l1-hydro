## Accès

Page : https://btraore850.github.io/cours-analyse-l1-hydro/tronc-commun/

Ce dossier **tronc-commun/** est indépendant des pages de cours Hydrologie situées à la racine du dépôt. Les fichiers d'origine ne sont pas supprimés ni modifiés.

## Publication de documents

Sur GitHub, ouvrez le dossier voulu puis **Add file → Upload files**, sélectionnez votre PDF (ou PPTX, DOCX, XLSX, R, PY, TEX, CSV, ZIP), puis **Commit changes** sur `main`.

- `tronc-commun/programme/` : programme officiel et présentation du programme.
- `tronc-commun/cours/` : polycopiés.
- `tronc-commun/presentations/` : présentations Beamer/PDF des chapitres.
- `tronc-commun/td/` : feuilles de TD.
- `tronc-commun/corriges/` : corrigés.
- `tronc-commun/tp/` : travaux pratiques et scripts.
- `tronc-commun/applications/` : données et études appliquées aux quatre filières.
- `tronc-commun/bibliographie/` : documents dont la redistribution est autorisée.

Les listes de fichiers des rubriques se construisent automatiquement par lecture de l'API publique GitHub ; si ce service est temporairement indisponible, un lien vers le dossier du dépôt est affiché.
